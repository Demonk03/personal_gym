# Personal Gym agent instructions

## Git workflow

- `main` is the only working and publishing branch. Commit directly on `main` and push only to `origin/main`. Do not create or use feature branches or pull-request branches.
- Verify relevant changes before committing or pushing. Push only by normal fast-forward; never force-push. If remote `main` has moved, stop and reconcile safely without discarding unrelated local work.

For project architecture, safety boundaries, rollout, and checks, see `CLAUDE.md`.
